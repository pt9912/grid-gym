# Archiv (verworfene / historische Skizzen)

Per [ADR 0001](../plan/adr/0001-documentation-and-planning-structure.md)
definierter Ablageort fuer **verworfene oder historische
Ideenskizzen** (archiviert = verworfen/ueberholt — im Unterschied zu
[`../plan/planning/done/`](../plan/planning/done/README.md)
= erfolgreich abgeschlossen und
[`../plan/planning/done-archive/`](../plan/planning/done-archive/README.md)
= eingefrorene Detail-Historie abgeschlossener Meilensteine).

Aktuell leer — Eintraege kommen per Verwerfungs-Entscheid hierher.
(Verzeichnis beim Post-M7-Doku-Sweep 2026-06-12 angelegt; es war
seit [`ADR 0001`](../plan/adr/0001-documentation-and-planning-structure.md) versprochen, aber nie materialisiert.)
